# Nova — GitHub Pages Website

A responsive starter website made with plain HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in your web browser.

## Publish with GitHub Pages
1. Create a repository on GitHub (for example, `my-website`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait a few minutes. GitHub will show your published website URL in the Pages section.

## Customize
- Change the title and visible copy in `index.html`.
- Change colors and layout in `style.css`.
- Change the contact email `hello@example.com` in `index.html` to your own email.
- Change the brand name `Nova` / `nova.` to your preferred name.

The contact button uses `mailto:` and opens the visitor's email app; it does not submit a server-side form.
